## Cara memasang
1. Unduh video (pilih resolusi 720p atau 1080p, durasi pendek 8-15 detik, kecilkan hingga di bawah sekitar 3 MB jika bisa).
2. Simpan sebagai `public/videos/hero.mp4`. Simpan satu gambar cuplikan sebagai `public/videos/hero.jpg`.
3. Buka `src/data/videos.ts` dan isi bagian `hero` seperti contoh di komentar. Lakukan hal sama untuk `intro`, `manfaat`, `penutup`.
4. Isi tabel di atas, lalu jalankan `npm run build`.
